# 사내 보고서 취합·편집 에이전트 (데모)

사업단이 제각각 만든 PPT 보고서를 **표준 양식으로 통일**하고, 페이지 단위로 수정하고,
근거를 붙여 질의응답하고, 하나로 병합하는 사내 도구입니다. 현재 데모 단계이며
DB·인증 없이 JSON 파일로 저장합니다.

## 실행 방법

```
run.bat        (Windows)
./run.sh       (macOS / Linux)
```

가상환경(.venv) 생성 → 의존성 설치 → uvicorn 실행까지 자동으로 진행되고,
브라우저에서 **http://127.0.0.1:8020** 을 엽니다.

수동 실행:

```
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python -m uvicorn app.main:app --port 8020
```

## 화면별 기능

| # | 화면 | 기능 |
|---|------|------|
| 1 | 현황 대시보드 | 등록 보고서·처리 완료·양식 오류·평균 처리 시간 집계, 오류 유형별 차트, 처리 완료 도넛 |
| 2 | 업로드 · 취합 | PPTX 드래그앤드롭 업로드(진행률 표시) → 추출 + 양식 검사, 통합 PPT 생성·다운로드<br>**양식 기준 직접 수정** (글꼴·크기·색·정리 규칙) 및 **기준 양식 PPTX 교체**(규칙 자동 실측) |
| 3 | 보고서 상세 | 원본 ↔ 표준 양식 적용본 비교(실제 양식 비율), 양식 위반 수정 내역, 보고서 내용 기반 AI 피드백 |
| 4 | 페이지 편집 | 개체 드래그 이동·크기 조절, 좌표·글꼴·색 편집, Undo/Redo(Ctrl+Z)<br>**캔버스 글자 더블클릭으로 내용 직접 수정**, 문단 추가·삭제·단계 조정<br>**양식 오류 목록과 자동 수정**(페이지별 / 전체) |
| 5 | 근거형 챗봇 | 업로드된 보고서 내용만 근거로 답변, [p.N] 출처 클릭 시 해당 페이지로 이동 |
| 6 | 동향 인사이트 | **보고서 키워드로 실제 뉴스 기사 검색**(구글 뉴스 RSS, API 키 불필요)<br>키워드 클릭·직접 검색 지원. 관계 그래프는 더미 데이터 |

모든 화면은 **반응형**입니다. 900px 이하에서는 사이드바가 상단 가로 내비게이션으로 바뀌고
카드·표·편집기가 세로로 재배치됩니다.

## 구조

```
app/
  main.py               FastAPI 진입점
  config.py             경로 상수
  routers/              reports · generate · layout · chat · rules
  services/             ingest(추출) · builder(PPTX 생성) · validator(양식 검사) · store · retrieve
  static/               SUNIC 디자인 UI (바닐라 JS)
  assets/               보고양식_Sample_4팀.pptx (표준 템플릿)
config/standard_rules.yaml   표준 양식 규칙 (실측 스펙 기반)
data/ uploads/ generated/    JSON 저장소 · 업로드 원본 · 생성 결과
```

## 양식 기준 바꾸기

`config/standard_rules.yaml` 이 단일 기준입니다. 바꾸는 방법은 세 가지입니다.

1. **화면에서 수정** — 업로드 · 취합 화면 → `기준 직접 수정` → 글꼴·크기·색 편집 후 저장
2. **양식 PPTX 교체** — `양식 PPTX로 교체` → 새 보고 양식을 올리면 좌표·글꼴·표 규격을 실측해
   규칙과 생성 템플릿을 함께 갱신합니다 (YAML을 직접 쓰지 않아도 됩니다)
3. **파일 직접 편집** — `config/standard_rules.yaml` 을 열어 수정

바꾼 기준은 이후의 양식 검사와 PPT 생성에 바로 반영됩니다. `기본값 복원` 으로 되돌릴 수 있습니다.

## 알려진 제약 (데모 단계)

- 저장은 JSON 파일 — 다중 사용자 동시 편집은 지원하지 않습니다.
- 원본 PPT의 이미지·차트 개체는 추출하지 않습니다(텍스트·표·타임라인만 이관).
- AI 피드백·챗봇은 기본적으로 TF-IDF + 규칙 기반 오프라인 응답입니다.
  `.env` 에 `LLM_MODEL` 과 `LLM_API_KEY` 를 채운 경우에만 외부 LLM을 호출합니다.
  호출 주소는 모델 이름으로 자동 판별합니다 — `claude-*` 는 Anthropic,
  `gpt-*` 는 OpenAI. 사내·로컬 LLM 서버를 쓸 때만 `LLM_API_URL` 을 지정하세요.
- 표준 양식 렌더링에는 나눔스퀘어(`NanumSquareR/EB.ttf`) 글꼴 설치가 필요합니다.
  미설치 시 PPT에서 대체 글꼴로 표시됩니다.
- 뉴스 검색은 구글 뉴스 RSS를 서버에서 호출합니다. 외부 접속이 막힌 사내망에서는
  기사 목록이 비고 사유가 표시됩니다(화면은 정상 동작).
- 동향 인사이트의 기업–기술 관계 그래프는 아직 더미 데이터입니다.
- 양식 검증은 텍스트·표 중심이며 이미지 개체 규격은 검사하지 않습니다.
