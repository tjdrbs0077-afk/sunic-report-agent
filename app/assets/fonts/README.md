# 표준 양식 글꼴 (나눔스퀘어)

생성되는 PPT는 `config/standard_rules.yaml` 의 기준대로 **나눔스퀘어 / 나눔스퀘어 ExtraBold**를
지정합니다. 파일 자체에는 글꼴 이름이 정확히 들어가므로, **PPT를 여는 PC에만 설치**하면 됩니다.
서버에는 설치할 필요가 없습니다.

## 설치 방법 (Windows)

1. 이 폴더의 `NanumSquareR.ttf`, `NanumSquareEB.ttf` 를 선택
2. 마우스 오른쪽 → **설치** (관리자 권한 불필요)
3. PowerPoint가 열려 있었다면 다시 실행

macOS 는 파일을 더블클릭 → "서체 설치" 를 누르면 됩니다.

| 파일 | PPT에서 쓰이는 이름 | 용도 |
|---|---|---|
| `NanumSquareR.ttf` | 나눔스퀘어 | 본문 |
| `NanumSquareEB.ttf` | 나눔스퀘어 ExtraBold | 제목·좌측 라벨·표 헤더 |
| `NanumSquareB.ttf` | 나눔스퀘어 Bold | (선택) 굵은 본문 |

## 설치 여부 확인

페이지 편집 화면의 글꼴 선택란에서 확인할 수 있습니다. 설치돼 있지 않으면 이름 뒤에
`(미설치)` 가 붙고, 상단에 안내 문구가 표시됩니다.

미설치 상태로 PPT를 열면 **파일은 정상이지만 화면에는 대체 글꼴로 보입니다.**
시연 PC에는 설치해 두는 것을 권합니다.

## 출처·라이선스

네이버가 배포하는 무료 글꼴입니다. 본 저장소에는 시연 편의를 위해 포함했습니다.
재배포 조건은 <https://hangeul.naver.com/font> 의 라이선스를 따릅니다.
`NanumSquare Neo` 는 패밀리 이름이 달라 대체용으로 쓸 수 없습니다.
